Memory sheet: Domain 4, operational efficiency

Exam weight 12 percent. Read this sheet, then answer the flash questions aloud.

Deciding rules

When the stem saysThink ofNot when
Steady, all-day, or reserved loadProvisioned ThroughputSpiky load, which pays for idle hours
Spike, sale, or unpredictable trafficOn-demand calls with token budgetsA steady load that costs less when reserved
Overnight, backlog, or by morningBatch inference from S3A chat screen waiting for each answer
Typing, first words, or a slow startResponse streamingA batch job with no user waiting
Same question, repeated, or nightly refreshCaching or precomputed answersPersonal answers, which must not be shared
Exact code, product number, or rare termHybrid searchA broad meaning question with no exact term
Spend jump across services or accountsCost Anomaly DetectionA runtime burst that needs an alarm now, since cost data can lag
Trend, spike, p50, or threshold on a metricCloudWatch metrics and alarmsOne slow request, where X-Ray shows the path

Etch lines

  1. Measure the prompt size before calling, and set an output ceiling.
  2. Average latency hides slow outliers, so check p50 and p90 too.
  3. TimeToFirstToken covers streams, while OTPS isolates model throughput.
  4. Steady or reserved wording signals Provisioned Throughput.
  5. Throttled calls are missing from Invocations, so check the throttle metric.
  6. Prompt text lives in invocation logs, while X-Ray covers timing.

Flash questions

  • Q: Which capacity model fits a steady load on one model all day? A: Provisioned Throughput.
  • Q: What does a token-burst alarm watch for each model? A: Sudden spikes in input or output token counts against a learned band.
  • Q: Which streaming metric shows the wait before the first token arrives? A: TimeToFirstToken.
  • Q: Which trace tool shows where time went across API Gateway, Lambda, and a model call? A: AWS X-Ray.
  • Q: How far can Cost Anomaly Detection data lag behind actual spend? A: Up to 24 hours.
  • Q: Which metric counts throttled model requests? A: InvocationThrottles.
  • Q: Name one kind of answer that should stay out of a shared cache. A: A personal answer.
  • Q: Which steps cut input tokens before each model call? A: Pruning history and chunks, plus compressing repeated instructions.
