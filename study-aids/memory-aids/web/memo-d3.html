Memory sheet: Domain 3, AI safety and governance

Exam weight 20 percent. Read this sheet, then answer the flash questions aloud.

Deciding rules

When the stem saysThink ofNot when
Stop, mask, block, or filter on a model callBedrock guardrail policyThe only need is proof of what happened
Who called, which identity, or which APIAWS CloudTrailThe exact prompt or response text is needed
Original request or what the model receivedModel invocation loggingThe policy forbids keeping prompt text
Find PII in stored S3 objectsAmazon MacieA live chat message, since Macie reads only S3 objects
Answer must be backed by retrieved passagesGrounding check in guardrailsA general question with no passage to score
Bias or drift over time against a baselineSageMaker Clarify bias drift monitoringOne bad answer that a filter must block now
Deploy only after an approval changeEventBridge rule on registry approval statusA text field that the deployment never reads
Filter one exact term in model outputWord filter in guardrailsA category of harmful language, which needs a content filter

Etch lines

  1. Model cards record a release but enforce nothing on their own.
  2. Guardrail traces hold raw PII in a match field, so guard them.
  3. Use CloudTrail for caller identity, call time, and API name.
  4. One wrong reply calls for a filter, while a drift pattern calls for a monitor.
  5. Macie reads stored S3 objects, never a live chat message.
  6. Redact first whenever the model must never see the raw value.

Flash questions

  • Q: Which control blocks or masks text on every model call under one policy? A: A Bedrock guardrail.
  • Q: A reviewer needs the exact prompt and response text for one call. Which record do you check? A: Model invocation logs.
  • Q: Which service finds PII spans in free text so your code can mask them? A: Amazon Comprehend.
  • Q: A RAG answer must be backed by retrieved passages. Which check fits? A: A grounding check.
  • Q: What does a Clarify bias drift monitor compare over time? A: Live bias against a baseline range.
  • Q: Which bucket policy condition limits reads to one VPC endpoint? A: aws:SourceVpce.
  • Q: What must a deployment read so an approval status works as a real gate? A: The registry approval status, read through an EventBridge rule or a pipeline check.
  • Q: Which filter matches a fixed list of exact terms in model output? A: A word filter.
