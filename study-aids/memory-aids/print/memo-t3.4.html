Memory sheet: Task 3.4 Implement responsible AI principles

Domain 3, weight 20 percent. Read this sheet, then answer the flash questions aloud.

Deciding rules

When the stem saysThink ofNot when
Explain why, show reasoning, or show each agent stepReasoning content block or agent traceA question about whether the answer is supported, since reasoning does not prove support
Cite, source, or where did this come fromCitations from a knowledge base, using RetrieveAndGenerateA claim that must be verified, since a citation does not prove the answer is right

Check text that code builds, with no model callApplyGuardrail, with the source set to OUTPUTA model call already on the path, which the guardrail on that call covers

Intended use, limitations, or risk ratingSageMaker model cardRuntime enforcement, since a card does not block anything

Etch lines

  1. A citation shows where a passage came from, not that it is right.
  2. Use ApplyGuardrail when code builds the text and no model call happens.
  3. Clarify measures group balance in data and predictions, not single sentences.
  4. A judge job scores fixed prompts against a rubric, offline.
  5. Prompt Management stores and compares prompt versions but does not score fairness.
  6. Lambda rule checks run before the response leaves the system.

Flash questions

  • Q: When a reasoning block comes back, what must you send on later Converse requests? A: The signature, with all earlier messages. A changed message makes the request fail.
  • Q: Does a citation prove that an answer is correct? A: No. It shows the source passage. Add a grounding check or a judge evaluation to verify the claim.
  • Q: Which API lets your code screen a template it fills in, when no model runs on that path? A: ApplyGuardrail, with the source set to OUTPUT.
  • Q: Which SageMaker feature reports bias numbers from a live endpoint to CloudWatch? A: Clarify bias drift monitoring, with metrics in a bias-metrics namespace for real-time endpoints.
  • Q: Which evaluation fits a stereotype check on one generated paragraph with a fixed test set? A: An LLM-as-a-judge job with the stereotyping metric.
  • Q: Which Bedrock feature stores prompt variants and versions that an app calls by ARN? A: Prompt Management. It stores and compares prompts but does not score fairness.
  • Q: On InvokeModel, which markup limits the text that a guardrail checks? A: guardContent tags around only the user text, with a new random suffix on each request.
  • Q: Which record documents limits and intended use without enforcing anything at runtime? A: A SageMaker model card. Pair it with a guardrail or a deployment gate.
