Etch lines

  1. Bedrock is managed, so you run no model servers and choose no instances.
  2. Run a bounded PoC with written pass criteria before any full build.
  3. A NAT route sends Bedrock calls out to the public internet.
  4. State the constraint in one line before you open the answer options.
  5. Converse suits one request shape across models that accept messages.
  6. Model Registry holds approval status, so deploy only Approved versions.

Flash questions

  • Q: Which managed service gives API access to foundation models without model servers to run? A: Amazon Bedrock.
  • Q: Which cross-Region profile keeps inference inside a named geography such as the European Union? A: A geographic profile.
  • Q: Why can a cross-Region inference profile not provide reserved capacity? A: Inference profiles do not support Provisioned Throughput.
  • Q: What share of traffic does a canary release send to the new version first? A: A small share, so the new version proves itself first.
  • Q: Which AWS feature changes application configuration without a code deployment and validates it first? A: AWS AppConfig.
  • Q: What must be deployed with a LoRA adapter for it to run? A: Its base model.
  • Q: Which endpoint name serves direct model calls such as Converse? A: bedrock-runtime.
  • Q: How does a production app keep rollback to one value change? A: It calls a numbered version ARN that sits in configuration.
