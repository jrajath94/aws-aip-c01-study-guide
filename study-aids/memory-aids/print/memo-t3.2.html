Memory sheet: Task 3.2 Implement data security and privacy controls

Domain 3, weight 20 percent. Read this sheet, then answer the flash questions aloud.

Deciding rules

Etch lines

  1. Each Bedrock API surface needs its own interface endpoint.
  2. A gateway endpoint serves S3 and DynamoDB only as a route table target.
  3. Hiding one column needs Lake Formation, not an IAM policy.
  4. Macie does not scan a live chat message, because it reads S3 objects only.
  5. A guardrail mask protects the answer, while the invocation log keeps the original request.
  6. With private DNS on, standard hostnames resolve to the endpoint, so code stays unchanged.

Flash questions

  • Q: Which endpoint type gives a private subnet S3 access with no NAT gateway? A: A gateway endpoint, added as a route table target in the same Region.
  • Q: Which Bedrock interface endpoint serves Converse and InvokeModel calls? A: The bedrock-runtime endpoint. The bedrock endpoint covers control plane actions only.
  • Q: A private app calls a model and invokes an agent. What is the minimum endpoint count? A: Two, bedrock-runtime and bedrock-agent-runtime.
  • Q: Which condition key shows that a request came through one endpoint? A: aws sourceVpce. It proves the network path, not the caller.
  • Q: Which service finds PII in data that is already stored in S3? A: Amazon Macie. It does not scan a live chat message.
  • Q: Does the real-time Comprehend PII response contain redacted text? A: No. It returns types, scores, and offsets, so your code applies the change.
  • Q: Does masking an answer with a guardrail change what the invocation log keeps? A: No. The log input still holds the original request.
  • Q: What does an S3 Lifecycle expiration action do, and what should you check first? A: It deletes objects after a set time. Check for a legal hold first.
