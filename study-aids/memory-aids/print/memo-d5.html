Memory sheet: Domain 5, testing and troubleshooting

Exam weight 11 percent. Read this sheet, then answer the flash questions aloud.

Deciding rules

When the stem saysThink ofNot when
Answer quality judged from several perspectivesLLM as a judge with rubrics, plus human reviewThe judge has not been checked against known answers
Compare models or settings on one datasetBedrock model evaluation jobsA single live session, which canary or shadow tests cover
Only the retrieved passages are in questionRetrieve-only evaluationThe generated answer itself must be judged for faithfulness
Release gate on fixed cases before promotionGolden dataset regression run in the pipelineThe risk only shows on real traffic, where a canary fits
A model update may shift answersPost-update validation with synthetic users and drift checksA question about speed alone, where latency metrics fit
Reply stops mid-sentence or ignores later textStop reason, then input size and dropped contextThe error is a throttle code, which needs quota metrics
Calls fail only inside a VPCRoute, private DNS, endpoint policy, and security group checksThe error is a plain quota or throttle code
Output format breaks a downstream parserSchema validation in codeA prompt sentence that asks for the format, since wording is only a request

Etch lines

  1. Latency charts cannot tell you whether an answer is right.
  2. Read the stop reason before you read the content of a reply.
  3. An LLM judge needs checks on known answers before you trust it.
  4. Change one prompt element per run so each result is traceable.
  5. Prompt wording can ask for a format, but only code enforces it.
  6. Test retrieval before generation to find whether the index or the model failed.

Flash questions

  • Q: Before trusting an LLM judge, what must you check first? A: Its scores on known good and known bad answers.
  • Q: Which Bedrock feature compares models on one dataset as a managed job? A: Bedrock model evaluation jobs.
  • Q: What should a golden dataset regression gate do when quality falls below its threshold? A: Fail the pipeline stage so the release stops.
  • Q: A reply stops mid-sentence. What do you check first? A: The stop reason, then input size and dropped context.
  • Q: Which four checks cover a call that fails only inside a VPC? A: Route, private DNS, endpoint policy actions, and security group rules.
  • Q: What does a 429 mean compared with a 503? A: 429 means the account exceeded its quota, and 503 means temporary service limits.
  • Q: When an answer cites the wrong section, which test runs first? A: Retrieve, because the passage is wrong before the answer is written.
  • Q: What helps a dashboard show which prompt version produced each result? A: Tagging logs with the prompt version.
