Memory sheet: Task 1.1 Analyze requirements and design GenAI solutions

Domain 1, weight 31 percent. Read this sheet, then answer the flash questions aloud.

Deciding rules

When the stem saysThink ofNot when
The provider hosts the model and no instance choice is neededAmazon Bedrock with the bedrock-runtime endpointThe team must own the weights or pick the instance type
The team owns fine-tuned weights or the serving containerSageMaker AI endpoint with deployment guardrailsThe stem only needs API access to hosted foundation models
One message format across several chat modelsConverse on bedrock-runtimeThe stem requires the exact native body of one model
Many prompts and no user waits for each answerBatch inference from S3A live chat window must show the answer as it arrives
Steady, predictable load on one model with a committed budgetProvisioned Throughput in model unitsTraffic is spiky or unknown, which calls for on-demand inference
Residency rule names a geography such as the European UnionGeographic cross-Region inference profileOnly a cost goal is named, which points to a global profile
A small share of traffic must prove a new version firstCanary traffic shifting with CloudWatch alarmsRisk is low and the baking period is enough, which allows all at once

Etch lines

  1. Read the requirement and name the constraint before any option.
  2. The first split is who owns the model weights.
  3. NAT sends Bedrock traffic to the public internet, so it breaks a private rule.
  4. Batch inference reads prompts from S3 and writes answers back.
  5. Ask whether the stem wants one code path across models.
  6. Use a canary when a small share must prove the new version first.

Flash questions

  • Q: Which service fits when the provider hosts the model and no instance choice is needed? A: Amazon Bedrock, called through the bedrock-runtime endpoint.
  • Q: What three elements make a proof of concept count as evidence? A: Numeric pass criteria, a fixed test set, and a short time box.
  • Q: Why does a public leaderboard rank fall short as a reason to pick a model? A: It does not show how the model handles your documents or output schema.
  • Q: Which profile keeps processing inside a named geography? A: The geographic cross-Region profile, not the global one.
  • Q: Can an inference profile carry Provisioned Throughput? A: No, inference profiles do not support Provisioned Throughput.
  • Q: Which two layers must both allow a call through a private interface endpoint? A: The caller IAM policy and the endpoint policy.
  • Q: Which deployment mode sends a small share of traffic to the new version first? A: Canary, with CloudWatch alarms watching the new fleet.
  • Q: What does a generative AI design review add beyond the six pillars? A: The Generative AI Lens, loaded into the AWS WA Tool as a custom lens.
