Memory sheet: Task 3.1 Implement input and output safety controls

Domain 3, weight 20 percent. Read this sheet, then answer the flash questions aloud.

Etch lines

  1. Macie scans stored S3 objects, and never sits in a live request.
  2. Guardrails returns a policy decision, and Comprehend returns entity locations.
  3. Real-time Comprehend output lists locations, so your code must replace the spans.
  4. A denied topic uses plain language, and a word filter uses exact terms.
  5. A score blocks nothing until code applies a threshold.
  6. Wrap only user-controlled text in input tags for the prompt attack filter.

Flash questions

  • Q: Which control scans S3 buckets for sensitive data that already sits at rest? A: Amazon Macie, since it works on stored objects and not on live messages.
  • Q: Which guardrail policy type refuses a subject described in plain language? A: Denied topics, since they use a natural language definition.
  • Q: Does the content filter strength setting apply to a list of banned product names? A: No, strength applies to categories, so use word filters for exact names.
  • Q: Which Comprehend mode fits a live chat turn that needs PII locations now? A: Real-time analysis of one document, with your code replacing the spans.
  • Q: Does a guardrail on the model call check a tool result inside the request? A: No, toolResult content is not evaluated, so screen it with ApplyGuardrail or code.
  • Q: Which three inputs does a contextual grounding check need? A: The source passage, the user query, and the model response to guard.
  • Q: Does a schema-valid object prove that its values are true? A: No, a schema checks shape only, so use grounding or Automated Reasoning for facts.
  • Q: What does an empty outputs list from ApplyGuardrail mean? A: No action was taken, so an empty list is not a block.
