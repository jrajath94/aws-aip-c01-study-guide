Memory sheet: Networking for generative AI

Cross-domain networking sheet. Read this sheet, then answer the flash questions aloud.

Etch lines

  1. A NAT route still reaches Bedrock over the internet path.
  2. Begin with where the caller runs, then take the first settled branch.
  3. Gateway endpoints cover S3 and DynamoDB only, never Bedrock.
  4. A hang in a private subnet often traces back to a route or endpoint gap.
  5. Security groups remember replies, but network ACLs need explicit reply rules.
  6. A wider security group cannot fix a subnet ACL that already drops packets.

Flash questions

  • Q: A private Lambda function must call a model, and internet access is banned. What is the first fix? A: Add an interface endpoint for bedrock-runtime in the function subnets.
  • Q: Which endpoint type adds no extra charge and serves S3 through a route table? A: A gateway endpoint.
  • Q: Model calls work from a private subnet, but agent calls fail. What is missing? A: The bedrock-agent-runtime interface endpoint.
  • Q: Which gateway lets private subnets start outbound connections but blocks new inbound connections from the internet? A: A NAT gateway.
  • Q: Which hub connects many VPCs and an on-premises site? A: AWS Transit Gateway.
  • Q: A residency rule keeps inference inside one geography. Which profile type fits? A: A geographic cross-Region inference profile.
  • Q: A request is allowed by the security group, but the reply is blocked. Which layer is the likely cause? A: The network ACL, because it is stateless and needs its own reply rule.
  • Q: The network path works, but a principal gets a denial on data reads. Which policy do you change? A: The data access policy, which decides who may read or write.
