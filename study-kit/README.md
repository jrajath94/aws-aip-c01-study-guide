# AWS AIP-C01 study kit

Index of the study files in this folder. Each folder holds one topic set.

| Folder | Contents | Start with |
|---|---|---|
| `domain-modules/` | Five exam domains and networking, as print PDFs and HTML. `web-black/` holds the black web version. | `domain-modules/index.html` |
| `memory-aids/` | Tree-map memory sheets by domain, topic, and exam. `print/` holds PDFs and HTML. `web/` holds HTML. | `memory-aids/print/index.html` |
| `modules/` | Ten topic modules: service choice, safety and PII, RAG, agents, model access and cost, customization, operations and security, evaluation, integration, and confusable pairs. | `modules/index.html` |
| `crash-course/` | Full crash course, cheat sheet, mind map, and question patterns. | `crash-course/crash-course-full-guide.pdf` |
| `video-prompts/` | Prompt and scene notes for the study video. | `video-prompts/muse-prompt-summary.md` |

Files that contain exam-derived text are not in this folder.
