# Muse prompt: one visual treatise video for the AIP-C01 study guide

Copy the text from "PROMPT START" to "PROMPT END" into Muse.

PROMPT START

Make one video that teaches the full AWS Certified Generative AI Developer Professional (AIP-C01) study guide as a visual treatise. The learner is a visual learner with ADHD. Show one idea per scene. Keep each scene readable in a few seconds. Do not overwhelm the viewer.

Source of truth: the study guide version 22, article "AIP-C01 visual treatise". Use only facts that appear in the guide. If a fact is not in the guide, do not show it. Write "Not in source." when a scene needs a fact that the guide does not state.

Style rules:
- Plain white background in every scene. No gradient, no glow, no drop shadow, no decorative frame, no left-border card, no generic illustration.
- One typeface for all text: Inter. Use dark gray text (#1B1F24) for body text.
- Diagrams use boxes with thin dark outlines. Arrows show data flow in one direction.
- Use these colors with one fixed meaning each:
  - Blue (#1D4E89): exam task or exam domain reference.
  - Rust (#A4441C): exam trap or a common misconception.
  - Green (#3D7A4A): the correct pattern or the recommended choice.
  - Gray (#6B7280): a note that is Not in source.
  Never use color alone. Each colored element also has a text label.
- Bold the fact the learner must remember. Use italics for design guidance and for corrections.
- Do not show a watermark, a logo, a credit line, "generated by" text, a user name, a date, a prompt, or a tool name in any frame.
- Official AWS diagrams: where the scene names one, show the official AWS image. Source credits are not part of the video.

Language rules for all on-screen text and narration:
- Write in ASD-STE100 style. One meaning for each word. Use the same term every time.
- Use no contractions. Use no semicolons. Use no em dash. Use no en dash.
- Write each procedure step in the imperative mood. Use one action per step. Use 20 words at most per step.
- Write other sentences with 25 words at most. Each sentence has one topic.
- Do not use these words: delve, leverage, unlock, robust, seamless, nuanced, pivotal, landscape, realm, tapestry, underscore, harness, foster, groundbreaking, cutting-edge, game-changing, holistic, multifaceted.

Scene format: for each scene, give these items in this order:
1. Scene number and the guide part or unit ID.
2. Visual: the layout, the diagram, and the colors.
3. On-screen text: at most 12 words per line.
4. Narration: 2 sentences at most.
5. Exam tie: the domain and task number from the guide.
6. Color meaning: which color appears and what it means.

Scope: this prompt covers the curriculum only. Every scene comes from a guide unit. Trap notes are curriculum misconceptions sourced from official pages.
