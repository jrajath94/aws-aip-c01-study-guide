Two-day route

This schedule assumes prior AWS application experience. Use recall results to move time toward weak topics.

Day 1

  1. Read foundations and model interfaces.
  2. Trace ingestion, RAG, and retrieval controls.
  3. Study prompts, tools, agents, and integration.
  4. Attempt related questions without source notes.

Day 2

  1. Study safety, privacy, governance, and operations.
  2. Study evaluation and failure diagnosis.
  3. Complete the 75-question repository mock.
  4. Review each error and explain every rejected option.

Proposed allocation: 2 hours for foundations, 4 for RAG and agents, 3 for security and operations, 3 for the mock, 2 for review.

The mock reuses repository questions. Its raw score does not predict the AWS scaled score.
