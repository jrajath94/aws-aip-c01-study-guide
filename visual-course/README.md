2. Select actual size.
3. Select one PDF page per printed side.
4. Select duplex with short-edge flip.

## Limits

Coverage follows the 98 published skills.
It does not guarantee a pass or establish personal readiness.
Official practice question bodies require sign-in and remain unaudited.
The proposed practical walkthroughs are not executed lab evidence.

The file review checks known Unicode carriers and supported metadata indicators.
Pixel and proprietary statistical watermarks remain unverified.
