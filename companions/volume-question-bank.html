    Outer layer Claim

    Domain 1: Foundation Model Integration, Data Management, and Compliance (31% of the exam, 61 questions)

    The D1 decision reference is a ladder with five rungs. Rung 1 is prompt work: format, tone, examples, with no new knowledge and no infrastructure.

    Mechanism

    From the lessonD1 · Decision reference

    The D1 decision reference is a ladder with five rungs. Rung 1 is prompt work: format, tone, examples, with no new knowledge and no infrastructure. Rung 2 is RAG: private, current, or cited facts that the model lacks from its train set. Rung 3 is agents and tools: the system must call APIs, query databases, or chain steps. Rung 4 is fine-tuning: a repeat behavior or voice goes into the weights, with labeled data in S3 and in most cases Provisioned Throughput to serve. Rung 5 is a full custom model, and the source calls it almost never the exam answer. Skip a rung and you pay train costs for a retrieval problem, or retrain costs for a prompt problem.

    From the lessonD1 · Question families

    The families repeat that ladder under new clothes. A returns-policy case with quarterly change and a citation rule lands on rung 2: the fine-tune rival fails on cost per change and on citations, the giant prompt rival fails on fit and on citation support, and the train-from-scratch rival fails on scope. Model selection items test the pick process: constraints first, then a shortlist, then evidence. Data items test pipeline order: validate, process, format, enrich. Compliance items test which control proves which claim. Each explanation names the rung or the rule, so a miss teaches the ladder again.

    5 rungs prompt, RAG, agents, fine-tune, custom model in D1 Nugget 2 · From the lesson D1 · Decision reference The lesson Climb the ladder in order and stop at the cheapest rung that works: prompt, RAG, agents, fine-tune, custom model. Why it matters. Most D1 traps are rung skips. The stem facts pick the rung: new facts mean rung 2, actions mean rung 3, behavior means rung 4. Transfer. State the rung in your answer note before you check the key. A rung habit turns 61 questions into one decision repeated. UNIT 02 · AIP-C01

    IllustrationD1 · Ladder step-through

    Open each rung and read the test that moves you up.

    Rung 1 · Prompt work

    Format, tone, few-shot examples, chain-of-thought. Zero infrastructure. Move up when the model lacks facts, not style.

    Rung 2 · RAG

    Private, current, or cited facts. A knowledge base serves them at query time. Move up when the system must act, not just answer.

    Rung 3 · Agents and tools

    API calls, database queries, tool chains. Move up when a repeat behavior must live in the model itself.

    Rung 4 · Fine-tuning

    Labeled data in S3, a customization job, and in most cases Provisioned Throughput to serve. Move up almost never.

    Rung 5 · Custom model

    A full custom build. The source marks this rung as a distractor home: the exam almost never lands here.

    Outer layer Claim

    Domain 2: Implementation and Integration (26% of the exam, 51 questions)

    The D2 decision reference is an API match table. Same code across providers with tool use means Converse, with no exceptions.

    Mechanism

    From the lessonD2 · Decision reference

    The D2 decision reference is an API match table. Same code across providers with tool use means Converse, with no exceptions. Embeddings or provider-only parameters mean InvokeModel, because Converse cannot do embeddings. No one waits and hours are fine means batch inference, S3 in and S3 out. A steady base or a latency SLA means Provisioned Throughput, and the code must call the provisioned model ARN or throttles persist. Tokens that appear as they generate mean ConverseStream, and gateway time limits push delivery to WebSockets or SSE. A wrong row gives a ValidationException from a body mismatch, or throttles from a bypassed reservation.

    From the lessonD2 · Question families

    The families drill agents, the Converse API, Lambda and API Gateway, Step Functions, and event-driven pipelines. The signature item is the release that changes nothing: instructions and action groups update, the console test shows new behavior, and production stays old. The reason pattern is a release-order fault: the work sits in DRAFT, and the fix runs prepare-agent to cut a version, then points the prod alias at that version. Rival causes fail on mechanism: alias retarget has no hour-long delay, Lambda redeploys touch code that never changed, and the console test proves the draft only. Traffic items pair a baseline with spikes and land on the hybrid form: reserved capacity for the base, on-demand for the spikes.

    5 rows the API match table in the D2 decision reference Nugget 3 · From the lesson D2 · Decision reference The lesson The API table has five rows: Converse, InvokeModel, batch, Provisioned Throughput, ConverseStream. The scenario need picks the row. Why it matters. Each wrong row has a named failure: a ValidationException, a throttle, or a stream that never streams. The failure name in the stem often gives the row away. Transfer. Match need to row before you weigh brands. API shape errors outrank model taste in D2. UNIT 03 · AIP-C01

    Domain 3: AI Safety, Security, and Governance (20% of the exam, 41 questions)

    The D3 decision reference matches the stem verb to the guardrail control. Content filters manage profanity, violence, and jailbreak language, with prompt attack as its own category.

    Mechanism

    From the lessonD3 · Decision reference

    The D3 decision reference matches the stem verb to the guardrail control. Content filters manage profanity, violence, and jailbreak language, with prompt attack as its own category. Denied topics manage a ban on a subject. Word filters manage exact strings. Sensitive-information filters manage PII patterns. Contextual ground asks if the claim sits in the source. Automated Reasoning asks if the act breaks the formal rule. The source calls this table the favorite confusion set of the exam: a wrong control deploys fine and enforces nothing.

    From the lessonD3 · Question families

    The signature item bans medical diagnoses in a health chat, in direct or rephrased form. The denied topic wins because it states the ban in natural language and covers rephrases. A content filter fails: it scores toxicity categories, and no medical advice category exists to threshold. A word filter fails: exact disease lists miss rephrased asks and need constant updates. Other families cover IAM scope, KMS and VPC paths, audit trails, PII pipelines, and responsible AI duties. The reason pattern is constant: read the verb, pick the row, kill the controls that act on a unlike signal.

    6 controls guardrail controls split by signal type in D3 Nugget 4 · From the lesson D3 · Decision reference The lesson Read the verb, pick the row. Six guardrail controls split by signal type, and a control at the wrong signal enforces nothing. Why it matters. A deployed guardrail with the wrong control passes a config review and fails the requirement. D3 items test that gap again and again. Transfer. Name the signal before the tool: subject, string, pattern, source fit, or rule fit. The signal names the control. UNIT 04 · AIP-C01

    Domain 4: Operational Efficiency and Optimization for GenAI Applications (12% of the exam, 25 questions)

    The D4 decision reference matches the cost lever to the traffic shape and the symptom, never to the buzzword.

    Mechanism

    From the lessonD4 · Decision reference

    The D4 decision reference matches the cost lever to the traffic shape and the symptom, never to the buzzword. On-demand serves spiky or hard-to-predict traffic, because reserved capacity for bursts wastes money. Prompt cache serves one long static prefix on each call. Batch serves work where no one waits and hours are fine. Provisioned Throughput serves a steady base with throttles or a latency SLA. A cascade serves mixed difficulty: a cheap first step, with escalation on low confidence. The wrong lever costs real money: peak prices in quiet hours, or throttles under steady load.

    From the lessonD4 · Question families

    The signature item asks why temperature, top-p, and top-k cannot cut the token bill. The reason pattern splits control classes: those parameters shape randomness and output quality, and the bill is token count times model rate. Rivals fail on fact: the parameters exist, they carry no price, and cost work is possible with the right levers. Cost levers in this domain are model selection, cache, batch, and prompt compression. Latency items split perceived speed from total time, and quota items split rate, concurrency, and capacity.

    5 levers cost levers matched to traffic shapes in D4 Nugget 5 · From the lesson D4 · Decision reference The lesson Five cost levers map to five traffic shapes: on-demand, prompt cache, batch, Provisioned Throughput, cascade. Match the lever to the shape. Why it matters. Quality dials are not cost levers. A D4 stem that offers a sampling parameter as a cost fix sets the class-confusion trap. Transfer. Classify each offered control by what it moves: money, time, or randomness. Cross-class picks fail on class alone. UNIT 05 · AIP-C01

    Outer layer Claim

    Domain 5: Testing, Validation, and Troubleshooting (11% of the exam, 22 questions)

    The D5 decision reference is a debug order, and skipped steps cost hours. Whole documents in prompts cause silent truncation, so chunk and retrieval come first.

    Mechanism

    From the lessonD5 · Decision reference

    The D5 decision reference is a debug order, and skipped steps cost hours. Whole documents in prompts cause silent truncation, so chunk and retrieval come first. A ValidationException with sound permissions means a request body fault. An AccessDenied in one region means an availability fault. Changed behavior means a version compare against regression data, not a temperature tweak. A RAG system that sounds sure and is wrong needs a retrieval check first. Provisioned Throughput throttles need a route check to the provisioned ARN before a unit purchase.

    From the lessonD5 · Question families

    The signature item is the AccessDenied that lies. An app fails in one region and works in another with equal permissions. The cause is model availability in the region, not authorization. Rivals fail on scope: a policy typo fails in each region, a network path makes no authorization error, and a global delete breaks the work region too. Other families cover evaluation design, judge setup, golden datasets, regression gates, and monitor planes. The reason pattern is constant: fix the upstream layer first, because generation sits last in the chain.

    Retrieval first the first check in the D5 debug order Nugget 6 · From the lesson D5 · Decision reference The lesson Debug in order: retrieval, request body, region availability, version drift. Generation tuning comes last, and a first-step fix at the wrong layer wastes hours. Why it matters. Error names mislead on Bedrock. AccessDenied can mean not available, and the region split in the stem is the tell. Transfer. Trust the symptom pattern over the error label. Labels name the surface, patterns name the layer.     From the lesson Bonus · How to use the set

    Mechanism

    From the lessonBonus · How to use the set

    The bonus set runs one level above the main bank: longer multi-constraint stems and closer rivals. Do the set after the main bank. Sub-banks follow the domains, and the D1 sub-bank runs Q141 to Q156. Each explanation keeps the main bank shape: the winner reason, a failure clause per rival, and the trap name.

    From the lessonBonus · Worked reasoning pattern

    One D1 bonus item sets a hard pick: a knowledge base over more than 8 million support articles in English and Spanish, a p99 retrieval limit of 200 ms, and a small storage budget, with a choice of embed models and dimensions. The winner process runs need first: the multilingual need points to the multilingual embed model, and the storage and latency limits point to dimension tests on a golden set. Rivals fail on skipped steps: a default 1024-dimension pick ignores the language need and the budget, a two-model split doubles operations and blocks cross-language match, and a cheap pick with no test carries unmeasured quality risk on 8 million articles. The pattern is the bonus signature: the answer is a selection process, not a product name.

    Field Research Questions: 2026 passer-report patterns (8 questions, Q193 to Q200)

    From the lesson Field · The eight patterns

    Mechanism

    From the lessonField · The eight patterns

    Eight questions come from September 2026 passer reports and prep-material analysis. Each one targets a pattern the main bank underweights. Detect-versus-block guardrails: does the filter flag the hit or stop the request. Proactive token alerts: warnings land before a request nears the context limit. Fabricated service features: rivals name features that do not exist. Adjective precision: small stem words such as most and least flip the answer. Audit-trail selection: CloudTrail against CloudWatch Logs against custom metrics. Step Functions flavor choice: Standard against Express. Provisioned-throughput misuse: a base model ARN in place of the provisioned ARN. The evaluation ladder: automatic metrics against a judge against human review.

    From the lessonField · Worked reasoning pattern

    One field item asks for an alert before any request nears a model context limit, across calls with large document contexts. The winner counts input tokens before each call and alerts near the limit. Rivals fail on time order: a CloudWatch alarm on the InputTokenCount metric fires after the call runs, so an oversize request fails first, and the stem asks for a proactive guard. A catch-and-truncate retry fails the same stem rule. The pattern is the field signature: the time word in the stem decides.

    How the 75-question mock maps to the real exam

    From the lesson Mock · Conditions and score rule

    Mechanism

    From the lessonMock · Conditions and score rule

    Take the mock in one sit: 75 questions in 180 minutes, in order, with no answer peeks. The mock uses the real domain weights. Score one point per question, and only when you pick each correct option and no other option. At 80 percent or more, 60 of 75, book the exam. Below 70 percent, revisit the domains you miss most, redo their bank questions, then retake the mock.

    60 of 75 the timed mock score that says book the exam Nugget 9 · From the lesson Mock · Conditions and score rule The lesson The book threshold is 60 of 75 under timed conditions. Below 70 percent, the loop is domain review, bank redo, mock retake. Why it matters. Multi-select score is all-or-none per question in this mock. A near-complete set earns the same zero as a blank. Transfer. Grade with the harsh rule in practice. Soft self-grade inflates the readiness call. UNIT 09 · AIP-C01

    The scoring guide as a ruler

    The ruler turns a mock score into a verdict. Below 52, revisit the weak domains. From 52 to 60 is borderline.

    Mechanism

    From the lessonScoring guide · Bands

    The ruler turns a mock score into a verdict. Below 52, revisit the weak domains. From 52 to 60 is borderline. At 60 or more, you are ready. Count one point per question, with the full correct set and no extra picks. The real exam uses scaled score from 100 to 1000, with a pass at 750, and compensatory score across domains: a strong domain can balance a weak one. No official raw-score conversion exists, so the ruler is a readiness guide, not a score promise.

    750 the pass mark on the 100 to 1000 real exam scale Nugget 10 · From the lesson Scoring guide · Real exam scale The lesson The real exam scales from 100 to 1000 and passes at 750, with compensatory score across domains. The mock ruler is a readiness proxy, not a conversion. Why it matters. A strong domain can balance a weak one on the real score. The mock bands stay strict so the readiness call stays honest. Transfer. Keep proxy metrics strict and label them as proxies. A soft proxy makes a hard decision with bad data. UNIT 11 · AIP-C01
