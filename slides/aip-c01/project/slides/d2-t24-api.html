Task 2.4 · FM API integrations

Call models reliably

Call. Use Bedrock APIs for synchronous calls. Use an SDK with Amazon SQS for asynchronous work that can finish later.

Stream. Use Bedrock streaming APIs. Use WebSockets or server-sent events to show text in real time.

Recover. Use exponential backoff with jitter. Set a maximum attempt count. Use a fallback model. Set API Gateway rate limits.

Observe. Trace calls with AWS X-Ray. Log token counts per call.

Route. Use static configuration, Step Functions for content-based routing, or metric-based routing.

Exam trap: Retry storms. Retries need jitter, a maximum attempt count, and a fallback. A tight retry loop is never correct.
