Task 2.4 · FM API integrations

Call models reliably

Call. Use Bedrock APIs for synchronous calls. Use an SDK with Amazon SQS for asynchronous work.

Stream. Use Bedrock streaming APIs. Use WebSockets or server-sent events for real-time text.

Recover. Use exponential backoff with jitter. Set API Gateway rate limits. Use fallbacks. Trace calls with AWS X-Ray.

Route. Use static config, Step Functions for content-based routing, or metric-based routing.

Exam trap: Retry storms. Retries need jitter, a maximum attempt count, and a fallback. A tight retry loop is never correct.
