Prompt Flows or Step Functions

NeedUse
Fixed prompt chain with branching, built visually by non-engineersAmazon Bedrock Prompt Flows. Nodes for prompts, Knowledge Bases, and Lambda.
Durable workflow with waits, retries, and human approvalAWS Step Functions. Callback task tokens for approval.
Workflow that waits about 2 days for a personStep Functions Standard. Inference: a Flow is not the durable pause for days.

A Flow has no autonomous reasoning loop. An agent does. Pick the flow for predictable steps and the agent for open-ended tasks.

Exam trap: A Flow is not the durable orchestrator for a multi-day approval. Use Step Functions.
