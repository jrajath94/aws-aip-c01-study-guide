Task 1.5 · Citations and grounding

RetrieveAndGenerate gives the audit trail

RetrieveAndGenerate returns a generated answer with its source citations.

Citations are attribution. They meet an audit requirement with no custom code.

Contextual grounding evaluation gives a numeric score for each answer. Auditors can sample those scores.

For the least custom effort, use Knowledge Bases. A sync and one API call cover the flow.

Exam trap: A hand-built RAG pipeline with custom citation code is wrong when the scenario asks for least effort.
