Task 1.1 · Analyze requirements and design GenAI solutions

Design from the constraints, then prove with a proof of concept

Skill 1.1.1. Create architectures that fit business needs and technical constraints. Choose the FMs, the integration pattern, and the deployment strategy.

Skill 1.1.2. Build a proof of concept to test feasibility, performance, and value. Use on-demand inference first. Example: Amazon Bedrock.

Skill 1.1.3. Create standard components for consistent deployments. Use the AWS Well-Architected Framework and the GenAI Lens in the AWS Well-Architected Tool.

Exam trap: Buying Provisioned Throughput before a proof of concept is a distractor pattern. Prove the approach first.
