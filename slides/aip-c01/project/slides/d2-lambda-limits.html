Task 2.2 · Lambda limits and orchestration

Lambda runs steps. Step Functions runs the flow.

A Lambda function runs for at most 15 minutes.

A 45-minute orchestration cannot run inside one function.

Waits in Lambda bill for the full duration.

Step Functions keeps durable state, waits, human task tokens, and retries.

API Gateway REST integrations stop at 29 seconds. Use streaming or an async job for longer work.

Exam trap: Put the long flow in Step Functions. Keep each Lambda step short.
