Task 2.1 · Session and customer memory

Use DynamoDB for memory that lasts weeks

RequirementDynamoDB answer
Millisecond lookup by customer or session IDKey-value design with the ID as the key.
Encryption at restServer-side encryption.
Expire old recordsNative TTL.
Memory for weeksDurable. Separate from the agent session TTL of 600 seconds.

The agent session expires. Customer memory must outlive it.

Exam trap: S3 is a poor fit for frequent small reads and writes per turn.
