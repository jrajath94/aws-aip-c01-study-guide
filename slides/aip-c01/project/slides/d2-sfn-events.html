Exam trap: CloudTrail records API calls for audit. It does not trigger processing. Use S3 events and EventBridge.

Long waits: Lambda has a 15-minute ceiling. Use Step Functions Standard with task tokens for waits and human approvals.

Session state: Use DynamoDB with TTL. S3 is a poor fit for chat session state.
