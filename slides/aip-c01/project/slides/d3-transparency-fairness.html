Task 3.4 · Transparency and fair design

Explain each decision with sources, signals, and traces

A loan decision needs an explanation that a person can verify. It cites the facts used.

Add confidence signals and reasoning traces to the output.

Use retrieval-grounded generation. Measure faithfulness before launch.

Define fairness metrics before the build. A/B test prompt variants for different impact.

Evaluate at scale with an LLM-as-a-judge. Five examples do not prove fairness.

A bigger model is not fairer by default.
