Task 3.2 · Data scope and regions

Cross-region safety checks can break an EU-only rule

EU request
Guardrail routed to another region
Data processed outside the EU

Cross-region guardrail inference gives safety failover between regions.

Routing processes the data in the destination region. This conflicts with strict EU-only processing.

Keep guardrail processing inside the EU. Accept the loss of cross-region failover for this check.

Exam trap: Failover that moves data across borders is wrong when the rule is EU-only.
