Task 3.2 · Data security plane

Isolate, encrypt, and limit access

Network: VPC endpoints keep traffic off the public internet.

Access: IAM least privilege. AWS Lake Formation for granular data access.

Encryption: AWS KMS for data at rest. TLS protects data in transit only.

Monitoring: CloudWatch and CloudTrail record data access.

Exam fact: AWS does not train models on your prompts or data. Encryption does not answer a training-use concern.
