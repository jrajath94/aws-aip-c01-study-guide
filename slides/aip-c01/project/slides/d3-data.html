Task 3.2 · Data security plane

Isolate, encrypt, and limit access

PlaneControl
NetworkVPC interface endpoints (PrivateLink) keep traffic off the public internet.
AccessIAM least privilege. Lake Formation for column and row access to lake tables.
EncryptionAWS KMS for data at rest. TLS for data in transit.
MonitoringCloudWatch and CloudTrail record data access and API calls.

Encryption answers storage risk. It does not answer a training-use question. Check the provider data terms for that.

Exam fact: AWS does not train models on your prompts or data. Encryption does not answer a training-use concern.
