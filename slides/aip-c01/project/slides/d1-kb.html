Task 1.5 · Managed RAG or hand-built RAG

Knowledge Bases is the default. Build your own only when forced.

Scenario wordsChoice
Private documents, citations, least custom effortBedrock Knowledge Bases. Sync, then one API call. Citations included.
Web pages tracked on a scheduleKnowledge Bases web crawler source with scheduled re-crawls.
Custom retrieval algorithm requiredHand-built RAG on the stated requirement only.

Knowledge Bases supports S3, Confluence, Salesforce, and web crawler sources. It manages chunking, embedding, and retrieval.

Exam trap: A hand-built pipeline is a distractor unless the scenario needs something Knowledge Bases cannot do.
