Task 2.3 · GenAI gateway, access, and release gates

One gateway enforces policy for every team

Teams and apps
GenAI gateway
Models

The gateway enforces guardrail and IAM policy in one place. For example, it enforces the guardrail identifier on every call.

It sends uniform logs and tags token spend for each team. This supports cost attribution.

A policy change lands in one layer. Fifty apps do not change.

Identity Center gives federated role-based access. Each team gets only the models and data it needs.

An automated pipeline uses evaluation jobs as release gates. A failed gate blocks deployment.

Exam trap: Identity alone is not enough. Pair it with least-privilege policy on each model call.
