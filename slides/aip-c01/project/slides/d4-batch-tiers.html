Task 4.1 · Batch for work that can wait

Batch inference fits work that can wait for hours

Batch inference runs non-interactive bulk jobs.

Input comes from S3. Output goes to S3.

The price is about half the on-demand price.

The job can be ready before the next business day. It has no per-call throttling.

Exam trap: A user waiting on a chat reply needs on-demand, not batch.
