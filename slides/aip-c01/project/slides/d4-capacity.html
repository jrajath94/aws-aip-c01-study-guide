ConceptPurposeChoose for

Provisioned ThroughputReserves model unitsSteady, predictable traffic with a latency target

Use the profile ID for resilience. Use the provisioned model ARN for reserved capacity. The base model ID uses the shared on-demand pool.

Exam trap: Code that calls the base model ID does not use reserved capacity. Call the provisioned model ARN.
