Profiles, routers, and reserved capacity

ConceptPurposeChoose for
Cross-Region inference profileRoutes requests across Regions for throughput and availabilityAvailability and resilience
Intelligent prompt routerRoutes between two models in one family by predicted response quality and costCost
Provisioned ThroughputProvides model units of throughputSteady, predictable traffic

Use the profile ID for resilience. Use the provisioned model ARN for reserved capacity. Calls to the base model ID do not use Provisioned Throughput.

Exam trap: Code that calls the base model ID does not use reserved capacity. Call the provisioned model ARN.
