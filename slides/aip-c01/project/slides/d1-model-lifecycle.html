Task 1.2 · Model lifecycle

Every release is a version you can roll back

Train or edit
Register model version
Approve
Deploy, roll back if needed

A model registry groups model versions. It tracks the approval status of each version.

A pipeline with rollback makes a bad deployment reversible.

Approval status records whether a model version is approved for deployment.

CloudTrail records Amazon Bedrock API calls, including InvokeModel and Converse. Use it for the audit trail.

Exam trap: A model or prompt that changes in place has no safe rollback point.
