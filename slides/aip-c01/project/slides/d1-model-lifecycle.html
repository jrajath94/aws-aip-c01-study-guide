Task 1.2 · Model lifecycle

Every release is a version you can roll back

Train or edit
Register immutable version
Approve
Deploy, roll back if needed

A model registry stores immutable, versioned artifacts. Each version has a record that you can reference.

A pipeline with rollback makes a bad deployment reversible in minutes.

An approval workflow enforces the human gate before publication.

CloudTrail records each prompt API call. Use it for the audit trail of changes.

Exam trap: A model or prompt that changes in place has no safe rollback point.
