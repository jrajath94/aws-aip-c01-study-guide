Task 1.2 · Customize with the least effort

Climb the ladder one rung at a time

RungWhat it changes and when to use it
1. Prompt engineeringChanges the instructions only. Try this first.
2. RAGAdds private or current facts at query time. Gives citations.
3. LoRA fine-tuningChanges adapter weights only. Fast and cheap. Needs labeled examples.
4. DistillationA large model teaches a small model one narrow, high-volume task.

Supervised fine-tuning needs labeled examples. Example: 20,000 labeled tickets in S3 give those examples.

Apply the ladder to each part of the system. One system can use three rungs.

Exam trap: Fine-tuning does not fix facts that change. Use RAG for those facts.
