Task 1.4 · Knowledge Base data sources

Sync on a schedule, or ingest on an event

PatternFit
Sync scheduleYour own scheduler calls StartIngestionJob on a regular cadence, such as a quarterly refresh.
Event-driven ingestionYour own event handler calls StartIngestionJob. New vectors can take a few minutes to appear.
Web crawlerIncremental syncs add and update changed pages and remove pages no longer present.
Direct ingestionAdds, updates, or deletes files in one action with the KnowledgeBaseDocuments API. S3 and custom sources only.

Data sources include S3, Confluence, Salesforce, and web pages. Managed ingestion handles chunking and embedding.

Set the chunking strategy when you create the data source. To change it, add a new data source. Then sync it.

Exam trap: Crawl a set of sites with no custom crawler: use the web crawler source. New web crawler connectors on customer-managed knowledge bases end September 30, 2026.
