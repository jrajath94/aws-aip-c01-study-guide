Task 1.3 · Knowledge Base data sources

Sync on a schedule, or ingest on an event

PatternFit
Sync scheduleRegular cadence, such as a quarterly refresh.
Event-driven ingestionAn S3 event can start an ingestion job. Near-real-time updates.
Web crawlerScheduled re-crawls. Changed pages re-ingest automatically.
Direct ingestionAdds content without a full sync. Keeps availability near real time.

Data sources include S3, Confluence, Salesforce, and web pages. Managed ingestion handles chunking and embedding.

Set the chunking strategy when you create the data source. To change it, recreate the data source. Then sync.

Exam trap: Track a set of sites weekly with no custom crawler: use the web crawler source.
