Task 4.1 · Token economics

You pay for every input and output token

cost = (input tokens / 1,000 × input price) + (output tokens / 1,000 × output price)

Illustrative prices: 3 USD per million input tokens and 15 USD per million output tokens. A 4,000-token prompt and a 1,000-token reply cost 0.027 USD in total.

Output tokens cost five times input tokens at these prices. Chatty replies raise cost.
