Task 4.1 · Token economics

You pay for every input and output token

Cost = (input tokens ÷ 1,000 × input price) + (output tokens ÷ 1,000 × output price)

Illustrative input (not current prices)Value
Input price3 USD per million tokens
Output price15 USD per million tokens
Example request: 4,000 input and 1,000 output tokens0.027 USD total

At these prices, output costs five times input per token. Chatty replies raise cost. Set max tokens to cap the reply.
