Task 3.2 · PII across the lifecycle

Macie finds it at rest. Comprehend and Guardrails catch it in flight.

ServiceWhereJob
Amazon MacieData at rest in S3Discovers sensitive data in S3 objects.
Amazon ComprehendSingle text documentsReal-time PII entity detection for text up to 100 KB. Fits a moderator dashboard.
Bedrock GuardrailsModel input and outputSensitive information filters block or mask PII at the model call.

Example: Macie for 40 TB of S3 logs. Comprehend for each chat message. Guardrails for model traffic.

Exam trap: Macie does not watch live model traffic. Guardrails does not scan the whole bucket.
