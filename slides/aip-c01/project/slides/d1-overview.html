Domain 1 answers one question

How do you get the correct model, the correct data, and the correct controls into a working system on AWS?

Climb the ladder. Start with prompt engineering. Add RAG, then agents, then fine-tuning. Stop at the cheapest step that works.

Prefer managed and serverless services when they meet the requirement.

Map each constraint to one decision. "Cite sources" points to RAG. "Take actions" points to agents. "Stable behavior at high volume" points to fine-tuning.

Domain 1 covers six tasks: design, models, data, vector stores, retrieval, and prompt governance. Each task has its own slide in this domain.
