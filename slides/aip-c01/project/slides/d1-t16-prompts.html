Task 1.6 · Prompt governance

Control prompts like code

Instruct. Store role definitions and {{variables}} in Bedrock Prompt Management. Enforce responsible AI rules with Bedrock Guardrails. Set the output format with templates.

Govern. Keep parameterized templates in version control or S3. Use approval workflows before publication. Track use with CloudTrail. Log access in CloudWatch Logs.

Test. Use Lambda to check expected output. Use Step Functions to run edge cases. Use CloudWatch to catch prompt regressions.

Improve. Give structured inputs, a stated output format, chain-of-thought instructions where useful, and feedback loops.
