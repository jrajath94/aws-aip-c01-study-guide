Task 1.2 · Cross-region inference

Cross-region profiles spread load, not data residency

Request uses profile ID
Source region quota
Destination region

Call the inference profile ID. Example: us.anthropic.claude with the us. prefix. Do not call the base model ID.

The eu. prefix routes across EU regions on the AWS backbone.

Routing starts when the source region fails. The failover is automatic.

Quota comes from the source region. The system does not split quota across destinations.

Routed requests run in other regions. Data can leave the origin geography unless the profile scope keeps it inside.

Exam trap: A cross-region profile breaks a strict EU-only rule when it routes outside the EU. Check the profile scope.
