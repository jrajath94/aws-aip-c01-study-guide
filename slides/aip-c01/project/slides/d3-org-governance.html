Task 3.3 · Organization-wide controls

SCPs enforce rules across every account

Service control policies (SCPs) limit which models accounts can call.

An SCP can make the guardrail identifier mandatory on each request.

Use the bedrock:GuardrailIdentifier condition key to enforce this at the IAM layer.

Application code can be changed or skipped. The SCP still applies.

Exam trap: A guardrail that only the app code calls can be skipped. Enforce it at IAM.
