Task 3.1 · Accuracy checks

Grounding checks and reasoning checks

CheckQuestion it answers
Contextual groundingDoes the retrieved source support this response? Is the response relevant to the question? Targets hallucination. You set the threshold.
Automated ReasoningDoes the answer obey formal policy rules? Example: totals must match line items. Deterministic logic.

Fuzzy safety judgments use probabilistic classifiers. Formal rules use deterministic reasoning.

Use JSON Schema to enforce the shape of a structured output.

Exam trap: Grounding checks test support, not safety. Use content filters for harmful text.
