Task 3.1 · Defense in depth

An attack must pass four layers

1. Pre-filter. Comprehend PII detection. Custom classifier for abuse.
2. Guardrails. Prompt attack filter on input. Content and PII filters on output.
3. Lambda. Format checks. Allow-list checks. Business rules.
4. API Gateway. Throttling and usage plans.

Each layer fails sometimes. Layers use different controls, so a gap in one is covered by another.

Put the cheapest check first. Put the strictest check at the model boundary.
