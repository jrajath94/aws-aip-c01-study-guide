Task 3.1 · Defense in depth

An attack must pass four layers

1. Pre-filter

Comprehend PII detection. Custom classifier for abuse.

2. Guardrails

Prompt attack filter on input. Output filters.

3. Lambda

Format checks. Allow-list checks. Business rules.

4. API Gateway

Response filtering. Throttling.

Every layer fails sometimes. Stacking layers covers the gaps between them.
