ApplyGuardrail
Allow or block

ApplyGuardrail applies the same Bedrock safety policy to any model. Examples are OpenAI, Gemini, and self-hosted models.

It takes content and returns a safety check. It does not call the model.

Input screening and output screening are separate checks.

Exam trap: A non-Bedrock model does not need to switch to Converse to use ApplyGuardrail.
