Task 4.3 · Tracing, drift, and forensics

Each monitor sees a different failure

ToolFinds
X-Ray distributed tracingTime and failure in each agent step. Breaks the chain into parts.
Agent trace outputReasoning, tool selection, and tool results for each step.
SageMaker Model MonitorStatistical drift in structured features and predictions. Not free-text quality.
LLM-as-a-judge or golden comparisonFree-text answer quality over time.
Invocation logging with Logs InsightsExact request and response payloads. Search by time, user, or session.

Forensics needs the payloads. Metrics alone cannot rebuild what happened.

Exam trap: Model Monitor does not score answer quality. Use a judge or a golden set.
