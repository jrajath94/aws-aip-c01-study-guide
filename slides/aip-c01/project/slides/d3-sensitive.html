Task 3.2 · Privacy controls

Find PII, then redact or block it

Detect PII
Redact or block
Model sees less

Detect. Amazon Comprehend PII detection for text. Amazon Macie for data at rest in Amazon S3.

Protect. Sensitive information filters in Guardrails redact or block. Masking and anonymization also protect data. Translation does not hide PII.

Retain. Use S3 Lifecycle configurations for retention limits.

Exam trap: The sensitive information filter can redact or block. Read the scenario to see which action it needs.
