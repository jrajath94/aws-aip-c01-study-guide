Detect: Amazon Comprehend PII detection. Amazon Macie for data at rest in Amazon S3.

Protect: Sensitive information filters in Guardrails can redact or block. Data masking and anonymization are also valid.

Keep: Use S3 Lifecycle configurations for retention limits.

Exam trap: The sensitive information filter can redact or block. Read the scenario to see which action it needs.
