Task 4.1 · Semantic cache

Cache by meaning, not by exact text

New question
Embedding similarity match
Stored answer

A semantic cache matches paraphrases of the same question.

Store the cache in ElastiCache or DynamoDB. Key the lookup by embedding similarity.

Prompt caching is different. It reuses an exact prompt prefix at the model.

The cache needs repeated, similar queries to get a good hit rate.

Exam trap: Highly personal queries rarely repeat. A semantic cache adds latency and saves little there.
