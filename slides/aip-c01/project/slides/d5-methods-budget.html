Task 5.1 · Evaluation methods within a budget

Cheap checks first. Judges next. People last.

StepMethod
1. AutomaticProgrammatic metrics on a built-in or custom dataset. Repeatable. Fits a 10,000-example nightly run.
2. LLM-as-a-judgeScores quality on the model that remains. Fits a 50,000-answer scale.
3. Human reviewOnly for the cases the judge cannot settle.

Bring-your-own-inference (BYOI) evaluation scores any model or full application output. You supply the responses.

Retrieve-only evaluation scores the retriever alone.

Exam trap: Bedrock-only evaluation misses an application that uses another model. Pick BYOI for that case.
