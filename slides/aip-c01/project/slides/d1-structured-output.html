Task 1.2 · Structured output

Use a schema, not a hope

Converse outputConfig takes a JSON schema. Generation returns JSON that is valid by that schema.

The schema works across providers. The code path stays the same.

Converse also sets messages, system prompts, and tool configuration the same way for every provider.

A schema is better than hope.

Exam trap: A prompt that asks for JSON does not guarantee valid JSON. Add the schema.
