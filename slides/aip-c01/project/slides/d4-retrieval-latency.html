Task 4.2 · Retrieval latency

Find the slow step, then fix that step

A latency profile that shows retrieval as the bottleneck points every fix at retrieval.

Optimized indexes and sharding cut the search time.

Preprocessing the query makes it smaller and faster to match.

Hybrid search with scoring finds better candidates in the same time.

Exam trap: A bigger model does not fix a slow search step.
