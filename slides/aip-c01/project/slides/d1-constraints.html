Task 1.1 and 1.2 · Constraints

Model selection solves a constraint problem

Remove each candidate that breaks one constraint. Keep the cheapest model that passes all of them.

Example: 40,000 transactions per hour and a 300 ms p99 budget. The mid-size model is the only one that meets both, if it also clears the accuracy bar.

Map each hard constraint to one design choice. Write the mapping down.

Exam trap: The flagship model is not the answer by default. It can break the latency budget.
