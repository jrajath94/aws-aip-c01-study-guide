Tasks 4.1 and 4.2 · Right-size the model

Route simple work to small models

PatternHow it works
CascadeTry the small model first. Escalate to a larger model when the answer is uncertain or the query is complex.
Route by complexityA classifier or prompt router sends each query to a model by complexity. Bedrock intelligent prompt routing does this as a managed feature.
Fine-tune smallA narrow, repeated task with stable rules and huge volume. Distill the behavior into a small model.

Tiered routing needs a complexity signal and a routing policy. Without the signal, the router cannot decide.

Exam trap: Prompts alone do not guarantee consistency at high volume. Fine-tuning fixes a stable pattern.
