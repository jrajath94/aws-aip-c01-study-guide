Task 5.1 · Judge calibration

Check the judge against humans before you trust it

Rate a fixed golden set with humans. Run the same set through the judge.

Measure judge-human agreement. Low agreement means the judge is not valid.

Pin the judge model version. A silent judge change moves every score.

Bedrock Model Evaluation jobs run automated, parallel judge evaluations. Connect them to the golden set.

Exam trap: An uncalibrated judge gives opinions, not measurements.
