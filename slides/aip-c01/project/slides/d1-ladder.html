The approach ladder: four rungs, cheapest first

RungUse whenSignal words
1. Prompt engineeringStart here. Cheapest step.Format, tone, instructions
2. RAGDocuments change often, or answers must cite sources.Private, current, cite, sources
3. AgentsThe model must take actions, such as calling tools or APIs.Take action, call, update a system
4. Fine-tuningStable behavior and a large, repeated task volume.Fixed format at high volume, distill

Stop at the cheapest rung that meets the requirement. Apply the ladder to each part of the system.

Exam trap: "Fine-tune the model on company documents" is wrong when the documents update regularly. Use RAG.
