Task 1.3 · Tenant and region isolation

Isolation must be structural

Use one knowledge base for each tenant. Each hotel or customer can have its own base.

Use IAM to scope each role to its own knowledge base. The platform enforces access.

Use metadata filters for region or product line. The filter applies before vector search, so the search stays limited and fast.

The model does not request access. It receives only what the retrieval layer returns.

Identity Center permission sets can map user groups to these roles.

Exam trap: A prompt that tells the model to ignore other tenants is not isolation.
