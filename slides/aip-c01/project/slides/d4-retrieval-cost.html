Tasks 4.1 and 4.2 · Semantic cache and retrieval

Cache by meaning. Retrieve fewer, better chunks.

Semantic caching

Repeated questions with different words. Example: a FAQ bot with millions of questions.

Answer from the cache before invoking the model.

Retrieval tuning

Lower top-k.

Rerank, then cut.

Use denser chunking.

Exam trap: Sending more chunks raises token cost. It does not raise answer quality by default.
