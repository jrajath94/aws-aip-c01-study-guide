Tasks 4.1 and 4.2 · Semantic cache and retrieval tuning

Cache by meaning. Retrieve fewer, better chunks.

Semantic cache

Repeated questions with different words. Example: a FAQ bot with millions of questions.

Look up the cache by embedding similarity. Return the stored answer before invoking the model.

Retrieval tuning

Lower top-k to send fewer chunks.

Rerank first, then cut to the top results.

Use chunk sizes that keep each answer complete.

Exam trap: Sending more chunks raises token cost. It does not raise answer quality by default.
