Q Developer, Q Business, and Amplify are different jobs

NeedService
Coding help in the IDE, code changes, test generation, CI workflowsAmazon Q Developer
Chat over company data for employeesAmazon Q Business
Web app with managed hosting, Cognito sign-in, and API integrationAWS Amplify. Little backend code.
Real-time collaborative editingAWS AppSync with DynamoDB
Mixed documents extracted at scaleBedrock Data Automation

Exam trap: Q Business and Q Developer have similar names. One does company chat. The other writes code.
