Task 4.2 · Sampling and variance

Randomness is a sampling problem, not a capacity problem

SettingEffect
TemperatureSets how wide the sampling is. Set to 0 for the most repeatable output.
Top-p and top-kLimit the candidate tokens. They shape the distribution.
Fixed seedRepeats sampling where the system supports it.
Versioned promptStops silent prompt changes from adding variance.

Sampling settings do not change the price per token. They do not reliably change token counts.

Provisioned Throughput buys reserved capacity. It does not fix output variance.

Exam trap: Buying capacity to fix different answers to the same input is wrong.
