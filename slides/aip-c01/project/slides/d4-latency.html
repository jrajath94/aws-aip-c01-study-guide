Task 4.2 · Latency and throughput

Latency is what the user feels. Throughput is what the system handles.

Perceived speed: stream the response as it generates.

Speed: use latency-optimized models for time-sensitive apps. Run parallel requests for complex workflows.

Precompute: generate answers for predictable queries ahead of time.

Volume: use batch inference for large offline work. Use Provisioned Throughput for steady capacity.
