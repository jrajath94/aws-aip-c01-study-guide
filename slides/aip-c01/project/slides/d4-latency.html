Task 4.2 · Latency and throughput

Latency is what the user feels. Throughput is what the system handles.

GoalLever
Perceived speedStream the response as it generates. The first token arrives in a fraction of the total time.
SpeedUse latency-optimized models for time-sensitive apps. Run parallel requests for complex workflows.
No waitPrecompute answers for predictable queries ahead of time.
VolumeBatch inference for large offline work. Provisioned Throughput for steady capacity.

Name the goal first. Streaming fixes perceived speed. It does not raise throughput.
