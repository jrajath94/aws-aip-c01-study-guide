Keyword search finds exact citation strings and codes. Semantic search finds related meaning.

Keyword-heavy queries drift when only semantic search runs.

The reranker scores candidates for true relevance. It runs before generation.

Exam trap: Similarity is not relevance. Reranking fixes ordering, not missing chunks.
