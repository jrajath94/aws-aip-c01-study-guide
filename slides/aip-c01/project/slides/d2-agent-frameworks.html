Task 2.1 · Open-source agent frameworks

Strands builds the agent. Agent Squad coordinates agents.

FrameworkRole
Strands AgentsCode-first framework for building one agent.
Agent SquadMulti-agent orchestration layer. Routes work among agents.

The exam guide names both as the open-source path. Both work with Bedrock Agents.

Choose a framework when the team needs code-level control. Choose a managed agent when the console is enough.

Exam trap: Match each requirement to one mechanism. Do not pick one service for every need.
