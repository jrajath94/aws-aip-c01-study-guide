Task 2.4 and 4.2 · Quotas and retries

Throttling needs backoff, jitter, and a limit

Rate limits and quotas cap requests and tokens. Watch them in CloudWatch.

Retry with exponential backoff and jitter. Set a maximum number of attempts.

Fall back to a second model or a cached answer when retries end.

Exam trap: A tight retry loop causes retry storms. It is never the answer.
