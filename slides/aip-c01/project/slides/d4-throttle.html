Tasks 2.4, 4.1, and 4.2 · Quotas, retries, and pre-call checks

Throttling needs backoff, jitter, and a limit

Quotas. Tokens per minute (TPM) and tokens per day (TPD) quotas cap token use. Watch InvocationThrottles in CloudWatch.

Retry. Use exponential backoff with jitter. Set a maximum number of attempts.

Fall back. Use a second model or a cached answer when retries end.

Check first. To avoid a context overflow, count tokens before the call with CountTokens. Compare the count with the model limit. Alert or truncate before invoking.

Exam trap: Retries that add load can make an overload worse. Back off with jitter.
