Prompt caching

Use for a repeated prompt prefix. The cached part must match exactly and sit before any changing content.

Cache writes cost extra. Caching pays off only with repeat volume.

Exam trap: Prompt caching fixes repeated-prefix cost. It does not guarantee throughput. Provisioned Throughput does.
