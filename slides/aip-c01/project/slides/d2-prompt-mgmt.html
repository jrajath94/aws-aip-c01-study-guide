Task 2.5 · Prompt management and caching

Variants test. Versions roll back.

ObjectJob
VariantCompare two wordings side by side. Use for A/B tests.
VersionImmutable snapshot of a prompt. Roll back to an earlier version.
Prompt cachingReuses a repeated prefix. The cached part must match exactly and sit before changing content.

Cache writes cost extra. Caching pays off only with repeat volume.

Exam trap: Prompt caching lowers the cost of a repeated prefix. It does not reserve throughput. Provisioned Throughput reserves capacity.
