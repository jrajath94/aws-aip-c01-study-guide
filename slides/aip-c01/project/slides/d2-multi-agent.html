Bedrock multi-agent collaboration is a built-in supervisor and collaborator pattern.

Each collaborator calls its own tools through an action group. Delegation is not an action group.

Frameworks: Strands Agents and AWS Agent Squad. Both are open-source paths named in the exam guide.

Tools: stateless MCP servers run on Lambda. Complex, stateful MCP servers run on Amazon ECS.

Exam trap: A DRAFT collaborator cannot take delegations. Prepare and alias it first.
