Task 4.1 · Prompt caching

Mark the static prefix. Pay less for each repeat.

Static prefix with cachePoint
Repeat call reuses prefix

A cachePoint marks a repeated prefix as cacheable. The static part of the prompt is the cache target.

Example: an 8,000-token prefix repeated on every conversational turn.

The default time to live is 5 minutes.

The prefix must meet the model's minimum token count. Minimums range from 512 to 4,096 tokens per cache checkpoint.

Exam trap: A changing user message in the prefix breaks the cache. Keep the variable part at the end.
