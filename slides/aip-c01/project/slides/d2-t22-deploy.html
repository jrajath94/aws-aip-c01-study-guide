Task 2.2 · Model deployment

Match the deployment to the traffic

OptionFits
On-demandSpiky or unknown traffic. Pay per token. No commitment.
Provisioned ThroughputA predictable baseline. Reserved model units. Hourly commitment.
SageMaker AI endpointsCustom or fine-tuned models. Real-time, serverless, or async.
Batch inferenceOffline sets that can wait for hours. About half the on-demand price.

For mixed traffic, use Provisioned Throughput for the baseline and on-demand for spikes.

Exam trap: The team bought Provisioned Throughput but still sees throttling. The code calls the base model ID. Call the provisioned model ARN instead. Adding model units is the distractor.
