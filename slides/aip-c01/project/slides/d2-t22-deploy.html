Task 2.2 · Model deployment

Match the deployment to the traffic

OptionFits
On-demandSpiky or unknown traffic. Pay per token.
Provisioned ThroughputA predictable baseline. Reserved model units.
SageMaker AI endpointsCustom or fine-tuned models. Hybrid setups.

For mixed traffic, use Provisioned Throughput for the baseline and on-demand for spikes.

Exam trap: The team bought Provisioned Throughput but still sees throttling. The code calls the base model ID. Route calls to the provisioned model ARN. Adding model units is the distractor.
