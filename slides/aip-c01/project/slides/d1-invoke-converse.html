Three ways to call a model

API styleUse it forNote
ConverseText generation through one interface for every modelNot for embeddings
InvokeModelModel-specific request bodies, including embeddingsUse for embedding models
StreamingIncremental output for real-time displayImproves perceived speed

Exam trap: Converse is offered as a distractor for embedding tasks. Embeddings need InvokeModel with an embedding model.
