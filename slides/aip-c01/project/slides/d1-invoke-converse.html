Task 1.2 · Calling models

Three ways to call a model

APIUse it forLimit
ConverseChat and tool use through one request format for every model.Text only. Cannot produce embeddings.
InvokeModelProvider-specific bodies. Embeddings.You build each provider's body.
ConverseStreamTokens as they arrive, for real-time display.Needs a client that reads a stream.

Streaming does not shorten total generation time. It shortens the time to the first visible token.

Exam trap: Converse is a distractor for embedding tasks. Embeddings need InvokeModel with an embedding model.
