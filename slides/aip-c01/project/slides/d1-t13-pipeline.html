Task 1.3 · Data validation and processing

Prepare data in four stages before the model reads it

1. Validate. AWS Glue Data Quality rules. Lambda checks. CloudWatch alerts.
2. Process. Bedrock Data Automation for documents, images, audio, and video. SageMaker Processing for batch jobs. Transcribe for speech.
3. Format. JSON for Bedrock API requests. Conversation format for dialog apps. Structured records for SageMaker endpoints.
4. Enhance. Comprehend extracts entities and detects PII. Bedrock reformats text. Lambda normalizes records.

Each tool serves one stage. Glue checks rules. Comprehend finds entities. Transcribe converts audio. Do not swap their jobs.

Exam trap: Guardrails do not validate data quality or extract fields. Match the tool to the stage.
