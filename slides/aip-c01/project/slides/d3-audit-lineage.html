Task 3.3 · Audit and lineage

CloudTrail shows who called. Lineage shows where the answer came from.

QuestionSource
Who called which API, when, and from whereCloudTrail. It is the API audit trail.
Which documents support this answerLineage from the data catalog, metadata tags, and output attribution.
Changes to a data set in real timeCloudTrail does not see inside rows. Use CDC, DMS, or event publishing.

No single feature gives full lineage. Combine catalog metadata with citations on each output.

Exam trap: CloudTrail questions ask for identity, timestamp, and API action. They do not ask for row content.
