Task 2.4 and 2.5 · Long responses

Streaming does not extend timeouts

REST API with streaming: still stops at the 29-second gateway limit. The study guide states this limit.

WebSockets: keep a long stream open. Use for long generation.

Asynchronous job: submit, then poll or receive a result later.

Exam trap: A 90-second model call fails at the gateway. Raising the Lambda timeout to 5 minutes does not fix it.
