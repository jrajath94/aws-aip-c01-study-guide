Task 2.4 and 2.5 · Long responses

Streaming does not extend timeouts

PathBehavior
REST API with streamingStill stops at the 29-second integration limit.
WebSocketsKeep a long stream open. Use for long generation.
Asynchronous jobSubmit the job, then poll or receive the result later.

Streaming improves perceived speed. It does not change the gateway timeout.

Exam trap: A 90-second model call fails at the gateway. Raising the Lambda timeout to 5 minutes does not fix it.
