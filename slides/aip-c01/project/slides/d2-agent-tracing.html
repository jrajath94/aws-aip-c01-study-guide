Task 2.1 and 4.3 · Agent tracing

The trace shows why the agent acted

Set enableTrace on invoke_agent. The trace emits one record for each step.

Each record shows the model reasoning, the action group chosen, the exact tool input, and the observation returned.

Use X-Ray across the agent steps when the chain spans several services.

CloudTrail records API calls. It does not show agent reasoning.

Exam trap: To debug one wrong tool choice, read the agent trace. Metrics alone do not show the step.
