Task 2.2 · Bedrock AgentCore

AgentCore runs any framework behind one interface

ComponentJob
RuntimeHosts agent code with any framework. Standard invocations interface, POST /invocations.
MemoryShort-term and long-term context for the agent.
GatewayExposes tools as MCP tools.
IdentityControls who and what can call the agent and tools.
ObservabilityTraces and metrics for agent steps.

Choose AgentCore when the team needs framework freedom with managed hosting.

Exam trap: AgentCore is not a model. It hosts and governs the agent around the model.
