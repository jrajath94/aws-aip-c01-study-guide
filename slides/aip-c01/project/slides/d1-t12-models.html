Task 1.2 · Skill 1.2.1

Choose a model on five axes

Capability

Reasoning, multilingual, code, vision.

Cost per token

Input and output prices differ.

Latency

Time to first token and tokens per second.

Context window

How much text fits in one call.

Regional availability

Is the model offered where you run?

Pick by latency needs first. Then pick by reasoning difficulty. Then evaluate on your own data.

Small models win on cost and latency for routine tasks.
