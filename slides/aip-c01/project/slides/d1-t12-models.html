Task 1.2 · Skill 1.2.1 · Select and configure FMs

Choose a model on five axes

AxisWhat to check
CapabilityReasoning, multilingual, code, vision.
Cost per tokenInput and output prices differ. Output is usually the larger cost.
LatencyTime to first token and tokens per second. Streaming improves perceived speed.
Context windowHow much text fits in one call, including retrieved chunks.
Regional availabilityIs the model offered in the Region where you run?

Order of decision: latency needs, then reasoning difficulty, then cost. Evaluate the final choice on your own data.

Small models win on cost and latency for routine tasks. Use a larger model only where the quality gap is measured.
