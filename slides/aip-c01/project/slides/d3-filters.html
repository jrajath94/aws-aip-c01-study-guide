Tasks 3.1 and 3.3 · Content safety

Content filters, denied topics, word filters

Content filters

Harmful categories, on input and output.

Prompt attack category checks input only.

Denied topics

Block a whole subject. Example: investment advice in a banking bot.

Word filters

Block exact words or phrases. Example: profanity in a tutor app.

Exam trap: Set the prompt attack filter off and jailbreaks reach the model. Attack detection runs only on input.
