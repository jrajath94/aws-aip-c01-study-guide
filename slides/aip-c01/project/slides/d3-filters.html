Tasks 3.1 and 3.3 · Content safety

Content filters, denied topics, word filters

FilterMatchesExample
Content filtersHarmful categories on input and output. Prompt attack category on input only.Hate, violence, injection
Denied topicsA whole subject, from a natural-language description.Investment advice in a banking bot
Word filtersExact words or phrases. Misses rephrasing.Profanity in a tutor app

Use denied topics for a subject. Use word filters for a fixed list. Use content filters for harm categories.

Exam trap: Turn the prompt attack filter off and jailbreaks reach the model. Attack detection runs only on input.
