Task 2.2 · Hosting MCP servers

Lambda hosts light MCP tools. ECS hosts heavy state.

ServerHost
Lightweight, stateless, bursty toolsLambda. Scales to zero. Sub-second billing.
Heavy, stateful pricing engineECS. Provisions memory and runs long-lived state.

Remote MCP servers use the Streamable HTTP transport.

STDIO is for local processes only. It is not a remote transport.

API Gateway fronts the server. Cognito OAuth authorizes users. AgentCore Gateway manages tool credentials.

Exam trap: STDIO for a remote MCP server is wrong.
