Task 3.1 and 4.3 · Detect mode

Detect mode reports without refusing

Detect mode runs the classifier. It reports the verdict.

It does not refuse the message. The conversation continues.

Intervene metrics fire on each detection. Notifications go out at once.

Use detect mode to measure a new rule before you block with it.

Exam trap: Detect mode is not a block. A blocked message needs intervene mode.
