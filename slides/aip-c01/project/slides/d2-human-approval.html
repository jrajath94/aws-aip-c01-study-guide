Task 2.2 · Human approval in a workflow

Pause with a task token, resume on approval

Agent drafts
Step Functions waits
Human approves or timeout

A callback task token pauses the workflow. The pause is durable.

The workflow waits for the approval or a 24-hour timeout. A variant uses a 4-hour timeout with automatic escalation.

The execution history and decision log give the audit trail.

Hours-long human waits need Standard workflows. Only Standard supports this pause, according to the question bank.

Exam trap: A Lambda that waits for a human pays for the wait and hits the 15-minute limit.
