Task 2.2 · Human approval in a workflow

Pause with a task token, resume on approval

Agent drafts
Step Functions waits
Human approves or timeout

A callback task token pauses the workflow. The pause is durable.

The workflow waits for the approval. The timeout length is Not in source.

The execution history gives the audit trail. Standard keeps it for up to 90 days.

Hours-long human waits need Standard workflows. Express workflows do not support the callback pattern.

Exam trap: A Lambda that waits for a human pays for the wait and hits the 15-minute limit.
