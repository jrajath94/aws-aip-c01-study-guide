Parts: the foundation model, instructions, action groups, knowledge bases, and the trace output.

An action group links the agent to a tool. Each tool call has a function schema and an executor.

invoke_agent takes agentId, agentAliasId, sessionId, and inputText. It returns a stream.

The sessionId is the memory key for one conversation. The alias pins the agent version.

Set enableTrace to get the per-step record of reasoning, tool choice, and results.

Exam trap: After any change, prepare the agent and move the alias. Otherwise callers run the old version.
