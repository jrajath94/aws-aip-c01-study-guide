Transparent, fair, and policy-checked

Transparent: show sources and reasoning. Use Amazon Bedrock agent tracing for reasoning traces.

Fair: track fairness metrics in CloudWatch. Use A/B tests and LLM-as-a-judge evaluations.

Compliant: apply Guardrails from policy requirements. Run Lambda compliance checks.

Key idea: Fairness is continuous. It is not a one-time check before launch.
