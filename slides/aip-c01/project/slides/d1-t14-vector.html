Task 1.4 · Vector stores

Pick the vector store for the data shape

OptionFits
Bedrock Knowledge BasesPrivate documents with citations. Managed RAG. The default answer.
OpenSearch ServerlessManaged vector search. Scales to zero. Combines filters and vectors.
Aurora with pgvectorVector search in a relational database the team already runs. Joins with rows.
S3 VectorsLarge, infrequent search. No always-on cluster. Latency in seconds.
DynamoDB with vectorsMetadata and embeddings in one table design.
NeptuneGraphRAG. Traverses explicit relationships such as compatible-with or replaces.
ElastiCacheNot a durable vector store. In-memory and ephemeral.

Exam trap: Neptune is a distractor for plain document search. ElastiCache is a trap for durable storage.
