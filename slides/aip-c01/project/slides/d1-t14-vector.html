Task 1.4 · Vector stores

Pick the vector store for the data shape

OptionFits
Bedrock Knowledge BasesPrivate documents with citations. Managed RAG. The default answer.
OpenSearch ServerlessManaged vector search. Scales compute up and down with usage. Combines filters and vectors.
Aurora with pgvectorVector search in a relational database the team already runs. Joins with rows.
S3 VectorsLarge, infrequent search. No infrastructure to provision. Sub-second latency for infrequent queries.
DynamoDB with vectorsMetadata and embeddings in one table design.
NeptuneGraphRAG. Traverses explicit relationships such as compatible-with or replaces.
ElastiCacheIn-memory cache service. Durable only with durability enabled on node-based Valkey clusters.

Exam trap: Neptune is a distractor for plain document search. ElastiCache is a trap when the question needs a durable store of record.
