Task 1.4 · Vector stores

Pick the vector store for the data shape

OptionFits
Bedrock Knowledge BasesPrivate documents with citations. Managed RAG. Default answer.
OpenSearch ServerlessManaged vector search. Scales to zero. Filters and vectors.
Aurora with pgvectorVector search in a relational database.
RDS with S3 documentsDocuments in S3. Metadata in a relational database.
DynamoDB with vectorsMetadata and embeddings in one table design.
NeptuneOnly when the scenario needs relationships or graph traversal.

Exam trap: Neptune is a distractor for plain document search. It is expensive for similarity search.
