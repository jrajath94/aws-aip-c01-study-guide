How AWS asks questions

Each stem gives a company, a constraint, and a broken design. Several options look right. One option satisfies every constraint.

Step 1. Read the constraint first. Examples: cost ceiling, latency budget, compliance rule, existing AWS footprint.

Step 2. Pick the option that meets all constraints at once.

Step 3. Choose the simplest managed option unless a constraint forces custom work.
