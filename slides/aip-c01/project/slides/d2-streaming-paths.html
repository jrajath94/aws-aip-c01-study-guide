Task 2.3 · Streaming to the browser

Tokens stream from the model to the browser

ConverseStream
WebSocket or SSE
Browser

ConverseStream and InvokeModelWithResponseStream send tokens as they arrive.

API Gateway WebSocket APIs or chunked transfer carry the stream to the browser.

API Gateway has payload and time limits. Long streams need WebSockets or direct streaming.

Client-side polling adds delay and load. Lambda does not poll.

Exam trap: Streaming does not extend the timeout. Pick a path that can hold the stream.
