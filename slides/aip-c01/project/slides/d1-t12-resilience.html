Switch, survive, and customize models

Switch without redeploy. Read the model ID from configuration. Use AWS AppConfig with Lambda and API Gateway. Changing the ID does not need a code release.

Survive disruptions. A circuit breaker stops calls to a failing model. Graceful degradation returns a smaller model or a cached answer. Cross-Region inference profiles give automatic failover when one Region fails.

Customize and retire. Fine-tune on SageMaker AI. Use LoRA to change only adapter weights, which is fast and cheap. Register each version in SageMaker Model Registry. Plan rollback and retirement.

Exam trap: "No code changes" or "no redeploy" means only the configuration-driven pattern qualifies.
