Switch, survive, and customize models

Switch models without redeploys

Read the model ID from configuration. Use AWS AppConfig with Lambda and API Gateway.

Survive disruptions

Use Step Functions circuit breakers. Use cross-Region inference when a model has limited regional availability. Degrade gracefully.

Deploy and retire customized models

Deploy fine-tuned models on SageMaker AI. Version them in SageMaker Model Registry. Use LoRA or adapters. Plan rollback and retirement.

Exam trap: "No code changes" or "no redeploy" means only the configuration-driven pattern qualifies.
