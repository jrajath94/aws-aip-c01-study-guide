Task 5.2 · Troubleshooting

Symptom, then likely cause, then first check

SymptomLikely causeFirst check
Output cut off mid-sentenceMax tokens too low. Context overflow.Max tokens. Token count against the limit.
Answer ignores the documentsRetrieval or chunkingRetrieved chunks, before the model
Output changes between runsSampling settings or prompt driftTemperature, seed, prompt version
Throttling after buying capacityBase model ID usedProvisioned model ARN in the call
Agent runs old behaviorAgent not prepared or alias not movedPrepare the agent. Check the alias version.

Exam trap: Traditional fixes do not solve GenAI faults. Temperature does not fix bad retrieval.
