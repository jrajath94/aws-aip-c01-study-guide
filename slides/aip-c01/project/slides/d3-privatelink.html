Task 3.2 · Private network access

PrivateLink keeps Bedrock traffic off the internet

VPC interface endpoints (PrivateLink) keep API traffic on the AWS private network.

They do not use NAT or the public internet.

Create one endpoint for each Bedrock plane the workload uses.

bedrock-runtime runs invocations. bedrock-agent and bedrock-agent-runtime serve agents. bedrock serves the control plane.

Exam trap: One endpoint for the runtime does not cover agent calls. Check each plane.
