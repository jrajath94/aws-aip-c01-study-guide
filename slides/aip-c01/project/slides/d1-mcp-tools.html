Task 2.1 · Tools for agents

MCP is one protocol for many tools

Model Context Protocol (MCP) sets a standard way for agents to find and use tools.

One protocol replaces a custom client for each tool.

The repo blueprint names MCP clients as the standard way to reach tools.

Remote MCP servers use Streamable HTTP.

Exam trap: MCP is the tool connection standard. It is not a model choice or a guardrail.
