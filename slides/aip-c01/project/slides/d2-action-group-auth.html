Task 2.1 · Action groups

An action group is the agent's tool, backed by a Lambda executor

An action group connects the agent to a tool. It defines a function schema the agent can call.

Use a Lambda executor for OAuth. The Lambda adds the token for each request and refreshes it.

The Lambda filters responses. It removes pagination details before results return to the model.

A basic schema cannot do authentication. It needs code.

Exam trap: A schema-only action group with an OAuth API fails. Add the Lambda executor.
