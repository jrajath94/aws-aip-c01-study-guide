Task 5.1 · Regression and release gates

Rerun the golden set on every change, then ship in stages

Change
Regression suite
Canary traffic
Full traffic

Regression suites rerun golden evaluations on every change. They catch drift.

Canary deployments limit the blast radius. A bad version reaches a small part of traffic first.

Gate each release in the pipeline. A failed gate blocks the deployment.

Exam trap: A re-sync or a prompt edit is a change. It needs the same gate.
