Task 2.3 · On-premises data

Outposts keeps AWS services on your premises

AWS Outposts extends AWS infrastructure and services to on-premises locations.

Data stays inside the bank's premises.

Teams use AWS APIs and managed services in that location.

VPC endpoints keep traffic on the private network.

Exam trap: A Region in the cloud does not keep data on the premises. Inference: use Outposts when the rule says the data stays on site.
