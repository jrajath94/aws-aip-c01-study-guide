Task 2.1 · Agent versions and aliases

DRAFT changes reach callers only through a version behind an alias

Edit DRAFT
Create version
Update alias
Callers reach the new version

Console tests run against DRAFT. A passing console test does not prove alias traffic works.

Aliases point to versions. Each version is a snapshot of the agent.

Configuration changes go to DRAFT. They do nothing for alias traffic until a new version is created and the alias points to it.

Callers send agentId and agentAliasId. Each alias gives a stable endpoint across version changes.

Exam trap: A new tool that works in the console but not in production usually means the alias still points to an older version.
