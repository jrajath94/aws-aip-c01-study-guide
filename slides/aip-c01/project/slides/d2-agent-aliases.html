Task 2.1 · Agent versions and aliases

DRAFT changes nothing for callers until you prepare and alias

Edit DRAFT
Prepare agent
New version
Alias points to it

Console tests run against DRAFT. A passing console test does not prove alias traffic works.

Aliases point only to prepared versions.

Configuration changes go to DRAFT. They do nothing for alias traffic until prepare-agent runs.

Callers send agentId and agentAliasId. Each alias gives a stable endpoint across version changes.

Exam trap: A new tool that works in the console but not in production is a missing prepare step.
