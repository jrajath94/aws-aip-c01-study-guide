Task 3.1 · Prompt attacks

Prompt attacks need their own detection

Prompt injection and jailbreak attempts are prompt attacks.

The prompt-attack content-filter category detects jailbreak and injection patterns.

It works on meaning, not exact strings. A word filter fails when the attacker rephrases.

Pair the prompt-attack filter with other controls on the same input.

Exam trap: A denied topic is not a prompt-attack detector. Prompt attacks are a separate feature.
